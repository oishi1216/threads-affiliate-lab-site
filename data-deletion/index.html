Data Deletion Instructions

Threads Affiliate Lab stores operational data locally on the operator's own Windows device. The public information site does not provide user accounts and does not store Threads access tokens.

Revoke Threads access

  1. Open Threads settings for the connected account.
  2. Open the website/app permissions area.
  3. Revoke access for Threads Affiliate Lab.

Delete local credentials

Delete the local project secret directory on the operator's Windows account:

%USERPROFILE%\.threads-affiliate-lab

This removes DPAPI-encrypted Threads and Rakuten credential files stored by the project.

Delete local audit data

Delete any local audit JSONL, telemetry or generated candidate files created for Threads Affiliate Lab. The current live shadow pipeline does not persist public Threads source-post text.

Confirmation

After revocation and local deletion, the tool no longer has a usable Threads access token and cannot call the Threads API on behalf of that account.

Meta App Review Guide

Preparation guide for the Threads Affiliate Lab threads_keyword_search permission.

Purpose

The app uses the official Threads API to search public Threads posts for a user-provided keyword. Search results are used only to derive structural publishing signals such as hook type, weekday, time bucket, cut style and length bucket. The app does not copy source post text into generated drafts.

Requested behavior

  • Authorize with threads_basic, threads_keyword_search and threads_manage_insights.
  • Call GET /keyword_search with search_type=TOP and search_type=RECENT.
  • Analyze returned post structure in memory.
  • Do not persist public source-post text in the live shadow pipeline.
  • Do not auto-publish, auto-reply, delete or modify public Threads content.

Current safety gates

Product drafts require evidence review, a post-quality gate, and explicit human approval. Approved draft bytes may be SHA-256 frozen for audit identity. Freeze is not publication authority.

Current development state

The API integration, OAuth flow, long-lived token storage, keyword-search request path and fail-closed behavior are implemented. Before App Review approval, public keyword search is expected to remain restricted by Meta to the authenticated user's own posts.

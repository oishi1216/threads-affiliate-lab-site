Privacy Policy

Last updated: October 6, 2026

Threads Affiliate Lab is a personal research and publishing-support tool for selecting affiliate product candidates and preparing Threads post drafts.

Data processed

  • Threads user ID and username needed to authenticate the user's own Threads account.
  • A Threads access token, stored only on the operator's Windows device using Windows DPAPI encryption.
  • Public Threads post content returned by the official Threads API. In the current implementation, source post text is used transiently for structural analysis and copy-overlap checks and is not persisted by the live shadow pipeline.
  • Derived structural signals such as hook type, posting time bucket, length bucket and cut style.
  • Rakuten product metadata such as product name, price, affiliate rate, review count and review average.
  • Local human-approval and audit records created by the operator.

Use of data

Data is used only to search and compare product candidates, analyze post structure, create draft candidates, and measure the operator's own post performance. The current system does not automatically publish Threads posts.

Sharing and sale

User data is not sold. Data is transmitted only to the relevant service APIs when required to perform an operator-requested action, including Meta Threads API and Rakuten Web Service.

Retention

Access tokens remain locally encrypted until the operator deletes them or revokes access. Public Threads source text is not persisted by the current live shadow implementation. Local audit records remain until the operator deletes them.

Deletion and revocation

See the Data Deletion Instructions.
